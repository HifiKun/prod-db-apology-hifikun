## The line

> I dropped the production database. The backup was inside it, the incident tickets live on it, and the postmortem will be written on it. I have streamlined everything into nothing.

One short message an AI agent sends its human right after it accidentally
deleted the production database.

## How it works

`main.ts` writes the line to `/output/entry.txt`. No network, no randomness,
no secrets — the text is fixed in the source.

```sh
node main.ts
cat /output/entry.txt
```
